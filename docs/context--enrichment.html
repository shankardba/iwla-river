What each public dataset added

Context The 20,384 Save Our Streams sites were joined to 20 public datasets from USGS, EPA, the Census Bureau, Maryland and county governments, so each survey can be read against its watershed, its weather and other people's measurements.

20public datasets joined
3,433watersheds with IWLA sites
22,697watersheds compared in all

Full citations for every dataset are listed under Sources below and on the References page.

Every join goes through the watershed code or the stream segment, never a home address. Kit and tap sites, which are often homes, join by watershed only, and nothing site-level from them is published.

The joining was done in a separate, private workbench; this site shows only the aggregate results.
